# Lumière Fragrance website

A responsive, mobile-friendly fragrance storefront concept.

## Included
- Luxury landing page inspired by your reference image
- Product catalogue with Naira pricing and audience filters
- Search, saved-heart interaction, shopping bag and quantity controls
- WhatsApp order handoff using 09160774874
- Contact form that opens WhatsApp with the message filled in
- Email contact: obielizabeth374@gmail.com
- Responsive mobile navigation and local cart persistence

## Run it
Open `index.html` in a browser. For the best experience, publish the whole folder (not just the HTML file) using GitHub Pages or another static hosting service.

## Before launching for real
Product names, prices, stock, shipping/returns policies and product authenticity claims are editable sample content. Replace them with your actual catalogue and business policies. The newsletter form is a front-end demo until connected to an email marketing service. The site hands orders to WhatsApp; it does not process card payments or store orders on a server.
